# Jack-Oso

## Datos básicos

| Campo | Valor |
|---|---|
| FUE / CON / TAM / INT / POD / DES / APA | 3D6+6 / 2D6+6 / 3D6+6 / 2D6 / 4D6 / 3D6 / 3D6 (medias ~16 / 13 / 16 / 7 / 14 / 10 / 10) |
| Puntos de vida | 15 |
| Modificador al daño | +1D6 aprox. |
| Puntos de magia | = POD; Mov 4, PF 30 |

Peludos musculosos con cabezas naranjas como calabazas; bosques y montañas; carnívoros caóticos.

## Ataques y armadura

Dos garras (D MR 7 / I MR 10), 25%+Manip., 1D6+1D6, a 3 MR entre sí + Hipnotismo MR 1 (+PM usados si potencia): PM vs PM, vencida queda congelada indefensa hasta muerte del jack o disipación (como divina 1 pto. a bloquear/disipar); gratis salvo potenciación; mantiene a POD/2 a la vez; no libera voluntario. Piel y pelaje 3 (cabeza); Esconderse/Deslizarse 60-10.
