# Trueque Conjuros

## Tipo

Divina.

## Culto de origen

[[Culto-Issaries]].

## Otros cultos que lo enseñan

- Exclusivo.

## Restricciones (quién NO puede usarlo)

No este mismo; no 1-uso poseedor; voluntario Mercado; Issaries exige beneficio.

## Requisitos

2 puntos con simbólico escudo cuchillo bolsa.

## Estadísticas

| Campo | Valor |
|---|---|
| Coste | 2 puntos |
| Alcance | Toque |
| Duración | Instantáneo hasta recambio o muerte |
| Acumulable | No |
| Reutilizable | Sí |

## Efecto

Cambia 1-uso reutilizable por otro ajeno; 1D100 01-95 pasa 96-00 activa contra otro como Solar; aunque falle puede recibir.

## Fuente

*Fuente: Dioses de Glorantha, p. 79.*
