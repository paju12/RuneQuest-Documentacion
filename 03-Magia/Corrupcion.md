# Corrupción

## Tipo

Divina.

## Culto de origen

[[Culto-Pocharngo]] requisito sacerdocio.

## Otros cultos que lo enseñan

- Exclusivo.

## Restricciones (quién NO puede usarlo)

Voluntario para sacerdote; hostil vence PM.

## Requisitos

4 puntos un solo uso.

## Estadísticas

| Campo | Valor |
|---|---|
| Coste | 4 puntos |
| Alcance | Toque |
| Duración | Instantáneo muta 1D10 asaltos |
| Acumulable | No |
| Reutilizable | No |

## Efecto

Transforma 2D6 par suma impar resta salvo ASP siempre resta, cero salvo ASP muere; solo Intervención detiene.

## Fuente

*Fuente: Dioses de Glorantha, p. 98.*
